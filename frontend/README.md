# Guida per avviare il frontend

## Installazione

1. Esegui `npm install` per installare le dipendenze.
2. Esegui `npm run dev` per avviare il server di sviluppo.
3. Esegui `npm run build` per costruire il progetto per la produzione.

## Note

Questa guida fornisce le istruzioni essenziali per avviare il frontend del progetto UnderTheSun.
